A complete story in exactly six words: "The lighthouse keeper lit nothing tonight." The keeper whose one job is the light leaves it dark — a whole life, and a whole night, implied in six words.

## Run it

```sh
python3 main.py
```

`main.py` reads the story from `story.txt`, checks it is exactly six words and 1–60 characters, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
